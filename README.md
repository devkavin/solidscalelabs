# Solid Scale Labs — Next.js (Enterprise Landing)

Modern, professional, UX-optimized, interactive landing page for Solid Scale Labs.

## Run locally

```bash
npm install
npm run dev
```

## What’s included

- Next.js App Router + TypeScript
- Tailwind CSS (working out of the box)
- Framer Motion micro-interactions
- Tabs, accordion, carousel, KPI counter
- Contact form posting to `/api/contact` (replace with your CRM/email provider)

## Customize

- Logo: `public/logo.png`
- Content/sections: `components/sections/*`
- Theme styles: `app/globals.css` and `tailwind.config.ts`
